## 과제 실행

Current Folder를 이 폴더로 설정한 뒤 MATLAB 명령창에서 실행합니다.

```matlab
ex_hw_1_202310841
```

`my_kmeans_202310841.m`은 입력 인자가 필요한 함수이므로 Run 버튼으로 단독 실행하는 대신 위 스크립트에서 호출합니다.
`grp = 3`은 군집 수, `class = [1 2 3]`은 군집에 붙일 번호입니다.

## K-means의 반복 과정

1. 초기 중심 K개를 선택합니다.
2. 각 데이터를 가장 가까운 중심에 배정합니다.
3. 각 군집의 평균으로 중심을 갱신합니다.
4. 새 중심으로 재배정합니다.
5. 이전과 배정이 같으면 종료하고, 다르면 중심 갱신을 반복합니다.

## 결과 해석

- K-means의 군집 번호는 실제 품종 번호와 직접 대응하지 않습니다.
- 군집 번호가 뒤바뀌면 같은 분할이어도 `mat_label - Final_label`이 0이 아닐 수 있습니다. 이 차이 그래프 자체는 정확도가 아닙니다.
- `ex2`의 내장 K-means는 초기 중심을 직접 구현과 동일하게 고정하지 않아 결과가 달라질 수 있습니다.
- 사용자 정의 코드는 강의 실습 형태를 유지했습니다. 빈 군집 처리나 최대 반복 횟수는 별도로 구현되어 있지 않습니다.
- 새로운 데이터로 확장할 때는 군집에 데이터가 하나뿐인 경우의 `mean(tmp_data)` 동작도 확인해야 합니다.

MATLAB과 Statistics and Machine Learning Toolbox가 필요합니다.
